# خلاصه قابلیت‌های پیشرفته GitHub Actions

## ۱. ساخت Docker Image در GitHub Actions

در این تمرین از GitHub Actions برای ساخت یک Docker Image استفاده کردیم.

## ۲. Dockerfile

در Dockerfile از Alpine Linux نسخه 3.19 به‌عنوان ایمیج پایه استفاده شده است.

دستور `CMD` مشخص می‌کند که هنگام اجرای کانتینر، عبارت زیر نمایش داده شود:

`hello from gitops-part1`

## ۳. Docker Buildx

از Docker Buildx برای ساخت ایمیج‌های Docker استفاده می‌شود.

این ابزار امکانات بیشتری برای فرایند Build در اختیار ما قرار می‌دهد.

## ۴. دستور Build and Push

از Action مربوط به `docker/build-push-action` برای ساخت Docker Image استفاده کردیم.

مقدار `push` برابر `false` قرار داده شده است؛ بنابراین ایمیج ساخته می‌شود اما به هیچ Registry ارسال نمی‌شود.

مقدار `load` برابر `true` است تا ایمیج ساخته‌شده در مخزن محلی Docker بارگذاری شود.

## ۵. Image Tags

برای ایمیج ساخته‌شده دو برچسب در نظر گرفته شده است:

- `latest`: برای مشخص کردن آخرین نسخه ایمیج
- شناسه Git Commit: برای شناسایی نسخه دقیق کد

## ۶. بررسی نتیجه

در پایان از دستور `docker images` برای مشاهده و بررسی ایمیج ساخته‌شده استفاده می‌کنیم.

## نتیجه‌گیری

در این تمرین با نحوه ساخت Docker Image به‌صورت خودکار در GitHub Actions، استفاده از Buildx و مدیریت برچسب‌های ایمیج آشنا شدیم.
