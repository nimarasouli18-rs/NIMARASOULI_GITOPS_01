# خلاصه مفاهیم Matrix، Artifact و Needs

## ۱. Matrix

قابلیت Matrix به ما اجازه می‌دهد یک Job را با چند تنظیمات یا نسخه مختلف اجرا کنیم.

در این پروژه، یک Job با دو نسخه Node.js یعنی نسخه‌های 18 و 20 به‌صورت جداگانه اجرا شده است.

## ۲. Artifact

Artifact برای ذخیره فایل‌هایی استفاده می‌شود که در طول اجرای Workflow تولید می‌شوند.

در این پروژه:
- از `upload-artifact` برای ذخیره و آپلود گزارش‌ها استفاده کردیم.
- از `download-artifact` برای دریافت گزارش‌ها در Job بعدی استفاده کردیم.

## ۳. Needs

کلمه کلیدی `needs` برای مشخص کردن وابستگی بین Jobها استفاده می‌شود.

در این پروژه، Job با نام `summarize` به Job با نام `test` وابسته است؛ بنابراین تا زمانی که Job تست با موفقیت تمام نشود، Job خلاصه‌سازی اجرا نخواهد شد.

## ۴. تفاوت Cache و Artifact

- Cache برای ذخیره وابستگی‌ها و داده‌های قابل استفاده مجدد به‌منظور افزایش سرعت اجرای Workflowهای بعدی استفاده می‌شود.
- Artifact برای ذخیره فایل‌های خروجی تولیدشده در طول اجرای Workflow استفاده می‌شود.
- هدف اصلی Cache افزایش سرعت اجرای فرایندهاست.
- هدف اصلی Artifact نگهداری، اشتراک‌گذاری و دانلود فایل‌های خروجی است.

## نتیجه‌گیری

در این تمرین با استفاده از Matrix دو نسخه Node.js را آزمایش کردیم، گزارش‌های تولیدشده را به‌صورت Artifact ذخیره کردیم و با استفاده از Needs ترتیب اجرای Jobها را مدیریت کردیم.
