# اصول GitOps

## 1. تعریف GitOps

GitOps روشی برای مدیریت و استقرار زیرساخت و برنامه‌هاست که در آن وضعیت مطلوب سیستم به صورت Declarative در Git نگهداری می‌شود. Git به عنوان منبع حقیقت (Source of Truth) استفاده می‌شود و تغییرات از طریق یک فرآیند خودکار به محیط اجرا اعمال می‌شوند.

## 2. چهار اصل OpenGitOps

### Declarative

وضعیت مطلوب سیستم به صورت شفاف و Declarative تعریف می‌شود؛ یعنی مشخص می‌کنیم سیستم باید در چه وضعیتی باشد، نه اینکه فقط مجموعه‌ای از دستورات برای رسیدن به آن وضعیت بنویسیم.

### Versioned & Immutable

تعریف وضعیت سیستم در Git ذخیره و نسخه‌بندی می‌شود و هر تغییر سابقه مشخصی دارد. بنابراین می‌توان تغییرات را بررسی و در صورت نیاز به نسخه قبلی بازگشت.

### Pulled Automatically

در مدل GitOps، یک Agent یا Controller در محیط مقصد وضعیت موردنظر را از Git دریافت می‌کند و لازم نیست CI مستقیماً به Cluster متصل شود.

### Continuously Reconciled

سیستم به صورت مداوم وضعیت واقعی محیط را با وضعیت تعریف‌شده در Git مقایسه می‌کند و در صورت وجود اختلاف تلاش می‌کند محیط را به وضعیت مطلوب برگرداند.

## 3. تفاوت CI، CD و GitOps

| مفهوم  | تمرکز                                                      | مثال ابزار              |
| ------ | ---------------------------------------------------------- | ----------------------- |
| CI     | Build، Test و بررسی تغییرات کد                             | GitHub Actions، Jenkins |
| CD     | استقرار نسخه جدید برنامه در محیط مقصد                      | Jenkins، GitHub Actions |
| GitOps | نگهداری وضعیت مطلوب در Git و هماهنگ‌سازی خودکار محیط با آن | Argo CD، Flux           |

## 4. اگر کسی دستی روی Cluster تغییر بدهد چه اتفاقی می‌افتد؟

فرض کنیم وضعیت مطلوب در Git این باشد که تعداد Replicaهای یک برنامه برابر 3 باشد، اما شخصی با kubectl تعداد Replicaها را به 5 تغییر دهد.

در مدل Pull-based GitOps، Controller وضعیت واقعی Cluster را با وضعیت موجود در Git مقایسه می‌کند. چون وضعیت واقعی با وضعیت مطلوب متفاوت است، Controller اختلاف را تشخیص می‌دهد و در صورت فعال بودن reconciliation، تغییر را اصلاح کرده و Cluster را دوباره به وضعیت تعریف‌شده در Git برمی‌گرداند.

به همین دلیل Git منبع حقیقت محسوب می‌شود.
